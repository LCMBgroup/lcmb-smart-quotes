# GHL Production Build Plan

## Goal

Move the front-end customer journey from GitHub into GHL once the flow is approved.

## GHL should handle

- Customer name
- Phone
- Email
- Suburb/address
- Floor plan upload
- Service pathway selected
- Bedrooms, bathrooms, living areas
- Storey type
- Home size
- Comfort/energy priorities
- Selected package style
- Preferred brands
- Add-ons
- Calendar booking
- Internal team notification
- Follow-up SMS/email

## Workflow

1. Customer completes smart selector.
2. GHL creates/updates contact.
3. GHL creates opportunity in the correct pipeline stage.
4. GHL stores floor plan file on the contact record.
5. GHL sends internal notification to LCMB.
6. Customer is shown booking options or sent a confirmation message.
7. LCMB confirms site inspection.
8. After site inspection, final quote is created in ServiceM8/GHL.
9. LCMB sends the final proposal link.

## AI stage later

After the form is producing clean submissions, add an AI step to create:

- Recommended product pathway
- Likely ducted size range
- Suggested number of outlets/zones
- Solar/battery size guidance
- Site inspection questions
- Draft proposal wording

LCMB must approve all final sizing, compliance and pricing.
