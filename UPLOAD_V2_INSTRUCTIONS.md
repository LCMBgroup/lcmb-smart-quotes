# Upload Professional V2 to GitHub

1. Unzip this pack.
2. Open your GitHub repo: `LCMBgroup/lcmb-smart-quotes`.
3. Click **Add file > Upload files**.
4. Upload these items from inside the unzipped folder, not the folder itself:
   - `assets/`
   - `quotes/`
   - `index.html`
   - `quote-generator.html`
   - `README.md`
   - `UPLOAD_V2_INSTRUCTIONS.md`
   - `prompt.md`
   - `robots.txt`
   - `.nojekyll`
5. Commit directly to the `main` branch.
6. Wait a few minutes.
7. Test:
   - `https://lcmbgroup.github.io/lcmb-smart-quotes/`
   - `https://lcmbgroup.github.io/lcmb-smart-quotes/quote-generator.html`
   - `https://lcmbgroup.github.io/lcmb-smart-quotes/quotes/example-quote.html`

If GitHub will not commit all files at once, upload in batches: first `index.html` and `quote-generator.html`, then `assets/`, then `quotes/`.
