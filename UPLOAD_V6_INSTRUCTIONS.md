# LCMB V6 Instant Estimate App - Upload Instructions

This version turns the smart selector into a modern mobile-first estimate experience inspired by high-converting quote funnels, but personalised for LCMB Group.

## Upload

1. Unzip the package.
2. Open `OPEN_THIS_FOLDER_UPLOAD_CONTENTS_TO_GITHUB`.
3. Upload the contents of that folder to the root of the GitHub repo.
4. Do not upload the folder itself.
5. Commit message: `Upgrade LCMB smart selector to V6 instant estimate app`.

Upload these items:

```text
assets/
quotes/
index.html
smart-selector.html
quote-generator.html
README.md
UPLOAD_V6_INSTRUCTIONS.md
PRODUCT_MATRIX_V6.md
GHL_PRODUCTION_BUILD_PLAN.md
prompt.md
robots.txt
.nojekyll
```
