# Privacy notes for the GitHub quote system

GitHub Pages is public web hosting.

This first version is intentionally simple and low-cost, but it is not the same as a private customer portal.

## Safer use

Use:
- Customer first name only
- Suburb only
- ServiceM8 job number
- Scope
- Price
- Payment terms

Avoid:
- Customer surname
- Customer phone number
- Customer email address
- Full address unless necessary and approved
- Internal notes
- Supplier prices
- Cost prices
- Margin
- Private site photos

## Search engines

This pack includes:
- `robots.txt`
- `noindex,nofollow` meta tags on pages

These help discourage indexing but are not a guarantee of privacy.

## Acceptance

The quote page has an Accept Quote button.

For best practice, paste the ServiceM8 or GHL acceptance link into the generator so acceptance is recorded in your official system.

If the acceptance link is left blank, the button will open an email acceptance fallback.
