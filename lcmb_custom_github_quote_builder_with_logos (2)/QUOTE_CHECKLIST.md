# LCMB quote page checklist

Before sending any GitHub quote link, check this list.

## Customer details

- Client name is correct.
- Address/suburb is correct.
- No unnecessary private information is shown.
- ServiceM8 job number is correct.
- Quote date is correct.
- Valid-until date is correct.

## Scope

- Scope matches ServiceM8/GHL.
- Inclusions are correct.
- Exclusions are correct.
- No AI-invented promises are included.
- No internal notes are visible.

## Pricing

- Line items match ServiceM8/GHL.
- Subtotal matches ServiceM8/GHL.
- GST matches ServiceM8/GHL.
- Total inc GST matches ServiceM8/GHL.
- Payment terms are correct.
- Deposit wording is correct.

## Buttons

- Accept Quote button works.
- Call button works.
- Email button works.
- ServiceM8/GHL acceptance link is included in the customer email/SMS.

## Mobile check

- Open the quote on your phone.
- Check the top section.
- Check pricing.
- Check buttons.
- Check photos.
- Check no weird formatting.

## Fallback

If it does not look right, do not send the GitHub quote. Send the standard ServiceM8/GHL quote instead.
